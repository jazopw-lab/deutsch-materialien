# Deutsch-Materialien – Fachschaft Deutsch FOSBOS Weiden

Lern-Apps für Schülerinnen und Schüler, gehostet über GitHub Pages: https://jazopw-lab.github.io/deutsch-materialien/

Die Apps sind offen zugänglich (kein Passwort, Ausnahmen in der Tabelle markiert) und laufen auch offline: `index.html` herunterladen und im Browser öffnen. Eingaben werden nur lokal im Browser des Geräts gespeichert.

```
klasse-11/   Apps Jahrgangsstufe 11
```
